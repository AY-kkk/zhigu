# 知股一期 MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. SPEC 明确：不因交接文档自动启动子 Agent。Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用户粘贴一个 A 股单公司投资观点，确认研究范围后，获得可追溯的支持证据、反证与未知项。

**Architecture:** Go 管产品与状态，Eino 是唯一总编排，Python 研究服务执行两个隔离、有界的研究 Loop。私有业务底座未发现项目级 LICENSE/NOTICE：不把其特有代码纳入可分发 `app/`；新建独立 Gin/GORM/Vue 宿主。不得静默更换业务底座。

**Tech Stack:** Vue 3 + Vite + Pinia + Element Plus；Go 1.24 + Gin/GORM + PostgreSQL + Eino；Python 3.12 + FastAPI + 固定提交 DeerFlow Harness（MIT）。

## Global Constraints

- 保留 GoSaaS＋Eino＋DeerFlow；不改成另一套全栈框架；不另做 Next.js 客户端。
- `references/` 只读、固定提交；业务代码只写 `app/`；不修改用户原有 GoSaaS 工程。
- 一个客户前端，一个业务写入者（Go），一个总调度器（Eino in-process）。Python 无业务数据库密码，不接受浏览器直连。
- 不做交易、个性化荐股排名、收益保证、长期偏好记忆、持续自选追踪、批量 PDF/OCR。
- 反证不是强行生成反话；允许找不到有效反证；允许最终证据不足。
- UI 不显示未经校验的模型草稿、隐藏思维链、密钥或工具原始日志。
- 不自动部署公网、创建远程仓库/PR、购买数据/API，或推送用户内容到额外服务。
- 新 finance API envelope：成功 `{"data":{...},"error":null,"trace_id":"..."}`；失败 `{"data":null,"error":{"code":"...","message":"..."},"trace_id":"..."}`。HTTP 200/201/202/400/401/403/404/409/422/429/503。
- 时间 RFC3339 带时区，服务端 UTC；金额与指标值为十进制字符串；JSON Schema `additionalProperties=false`，`schema_version="1.0"`。
- ID：业务实体用不透明字符串（生产 UUID；fixture 可用 `run_demo`）。`owner_id` 与 GoSaaS `SysUser.ID` 一致，类型 `uint`。
- 硬上限：每角色模型 4 / 工具 6；总模型 14 / 工具 12；解析通常 1；排队 30s；执行 180s；解析 5 次/用户/分钟；每日 10 个研究；追问每报告 3 轮、每轮 2 次模型、无外部工具。
- 输入预占上限 8,000 tokens、输出 1,200；每 run 累计输入 <=112,000、输出 <=16,800。
- 全局 2 个活动 run、每用户 1 个活动 run、Python 最多 4 个角色任务。活动态含 queued/researching/verifying/canceling，即使 `deleted_at` 非空也不释放并发。
- 金融工具恰好 3 个：`get_financials`、`search_filings`、`calculate_metric`。Harness 默认内置工具必须排除。`include_mcp=false`，`subagent_enabled=false`，`allowed_subagents=[]`，`skills=[]`，`memory_enabled=false`，`plan_mode=false`。
- fixture 证券 `DEMO:COMPANY`，mode 全程保留，前端不可隐藏 fixture 标识。
- 缺模型/数据凭据时做到阶段 A（fixture 可测闭环），不得伪造阶段 B/C 或公开运营资格。
- 先失败测试再最小实现；每任务更新 `app/IMPLEMENTATION_STATUS.md`；本地可提交，不自动 push。
- 用户最新指令 > PRD v2 > 架构 v2 > SPEC。旧《技术设计与开源复用》只作历史源码线索。

## Shared types (all later tasks consume these)

Go 文件 `app/server/service/finance/interfaces.go` 与 `types.go`；Python `app/research-service/app/schemas.py` 必须与 `app/contracts/*.schema.json` 字段一致，禁止两侧自创字段名。

```go
package finance

import (
	"context"
	"time"
)

type ResearchClient interface {
	Submit(ctx context.Context, task ResearchTask) (TaskReceipt, error)
	Get(ctx context.Context, taskID string) (TaskSnapshot, error)
	Cancel(ctx context.Context, taskID string) (TaskSnapshot, error)
}

type EvidenceGate interface {
	ValidateRole(ctx context.Context, run RunSnapshot, result ResearchResult) (ValidatedRole, error)
}

type BudgetService interface {
	Reserve(ctx context.Context, request BudgetRequest) (Reservation, error)
	Reconcile(ctx context.Context, reservationID string, usage ObservedUsage) error
}

type ReportPublisher interface {
	Publish(ctx context.Context, runID string, expectedVersion int64, report VerifiedReport) error
}

type TaskReceipt struct {
	TaskID string `json:"task_id"`
	Status string `json:"status"`
}

type TaskSnapshot struct {
	TaskID string          `json:"task_id"`
	Status string          `json:"status"` // queued|running|succeeded|insufficient|failed|canceled
	Result *ResearchResult `json:"result"`
}

type BudgetRequest struct {
	RequestID      string
	OwnerID        uint
	RunID          string
	TaskID         string
	ParseID        string
	QuestionID     string
	Purpose        string // parse|research|synthesize|verify|repair|question|admin_test
	Kind           string // model|tool
	BodyHash       string
	ReservedInput  int
	ReservedOutput int
}

type Reservation struct {
	ID            string
	RequestID     string
	Status        string // reserved
	ReservedInput int
	ReservedOutput int
}

type ObservedUsage struct {
	ActualInput       *int
	ActualOutput      *int
	Unknown           bool
	UpstreamRequestID string
}

type AppError struct {
	Class   string // validation|budget|timeout|transport|canceled|conflict|not_found|forbidden|unavailable
	Code    string
	Message string
	Retry   bool
}

func (e *AppError) Error() string { return e.Code + ": " + e.Message }
```

`ValidatedRole` 只能由闸门构造（未导出字段 + 包内 constructor）。`RunSnapshot` 为冻结 run：claim、instrument、as_of、mode、config_versions、budget_snapshot、deadline、owner_id、version、status。所有方法尊重 `ctx` deadline/cancel。
