# 知股 · 交易策略模块 PRD

版本：P-1.5 · 2026-09-23

状态：产品需求与构建规范，不代表功能已实现或通过验收。统一开发合同见 [阶段 B SPEC §12](../spec/阶段B_开发SPEC.md#12-策略市场数据库与前端开发合同b-s-01b-s-10)，计算细则见 [策略专项 SPEC](../spec/策略模块_开发SPEC.md)。本文明确产品定位和用户操作要求；策略纳入阶段 B 独立工作线，保留观点研究的三工具和报告边界。

## 1. 模块定位

**交易策略模块帮助用户完成「策略制作 + 策略回测查看」：把交易想法变成明确、可编辑的规则，再用历史数据检查这些规则的收益、风险与交易过程。**

核心用户是有交易想法、希望验证规则的个人投资者，**不要求会写代码、熟悉技术指标名称或先填完专业表单**。AI 辅助构建是主要入口：用户说出思路，AI 协助选择指标、填写参数并生成可编辑策略。现成策略或模板是制作起点，用户必须能查看、修改并保存为自己的策略；浏览策略列表不构成本模块的完整交付。

核心流程分两条入口，汇入同一制作与回测工作台：

- 从市场开始：**浏览策略市场 → 查看策略与证据 → 复制到我的策略 → 修改并回测。**
- 从想法开始：**说出交易思路 → AI 填充策略卡 → 补充关键缺项 → 确认并回测 → 对话修改。**

首版沿用既有范围：A 股／港股目录搜索，单股票、只做多、无杠杆的现金账户；按日线产生信号。周／月 K 可供查看，不代表支持周／月策略执行。回测为历史模拟，不包含券商实盘下单。

### 1.1 二级页面与本轮优先级

在一级导航「交易策略」下设置两个二级入口，策略市场拥有独立页面：

```text
交易策略
├─ 策略市场       /app/strategies/market
│  └─ 策略详情    /app/strategies/market/:strategyId
└─ 策略工作台     /app/strategies
   ├─ 我的策略／AI 创建／买卖规则配置
   └─ 当前回测结果／回测记录
```

本轮优先建设策略市场的列表、详情及复制入口；保留现有工作台路径，市场入口在交易策略内部可见，不强制重定向正在编辑的用户。详情页可返回原筛选结果；手机同样提供可见的二级切换。这里定义的是页面与功能需求，不表示界面已经实现。

首版采用平台整理与审核的策略目录。用户投稿、付费购买、订阅分成和自动跟单列为后续扩展，不是本轮依赖。策略市场为策略制作提供起点，原有 AI 构建、规则编辑和回测目标继续保留。

## 2. 一套完整策略需要定义什么

完整策略必须回答：**买什么、用多少钱、买多少、什么时候买、什么时候卖、亏到什么程度退出、多久检查一次以及何时执行。**

以下区分两类信息：交易规则决定如何交易；回测配置决定用什么资金、历史区间和成本假设验证。两者共同构成一次回测的完整输入。

### 2.1 策略规则

| 要素 | 简明定义 | 填写规范与首版要求 |
|---|---|---|
| 策略名称与标的 | 这是什么策略，交易哪只股票 | 名称可编辑；股票必须确定代码、交易所和柜台币种，重名时由用户选择 |
| 买入点 | 满足什么条件才产生买入信号 | 写清指标、参数、比较值及「同时满足／任一满足」。例如空仓时 MACD 金叉且 KDJ 的 K＜30；不能只写「低位买入」 |
| 仓位与资金分配 | 每次买入使用多少资金 | 按账户权益设置目标仓位，范围大于 0 且不超过 100%；例如 50%。首版空仓入场，持仓时不重复加仓；实际数量受现金、费用和交易单位约束 |
| 卖出点 | 正常情况下满足什么条件退出 | 明确退出条件及卖出范围；首版触发后退出全部可卖持仓。例如 MACD 死叉后退出；不得只写「高位卖出」 |
| 止损点 | 亏损达到什么条件时退出 | 必须明确「启用及阈值」或「不启用」。首版按每日收盘时本轮持仓净收益率检查，例如 ≤−5%；包含买入成本、已实现卖出净额及已确认股息，不等同于股价简单下跌 5% |
| 止盈与持有期限 | 是否达到盈利目标或持有上限就退出 | 可启用固定止盈比例、最大持有交易日数，或明确不启用；止盈采用与止损相同的净收益口径，持有天数从首次成交日计 1 |
| 执行周期 | 多久判断一次，信号何时变成订单 | 分开展示「信号周期：日线」「检查时点：收盘后」「模拟执行：下一交易日开盘」。不能只填写含糊的「每天执行」 |
| 规则优先级 | 多个条件同时出现时怎么办 | 退出优先；正常卖出、止损、止盈和到期退出合并为一次退出；退出当日不重新买入 |
| 指标与价格口径 | 规则依据哪些数据计算 | 显示全部指标参数和信号价格口径；首版默认按当时可获得的复权信息计算信号，用原始价格模拟成交；图表调整不自动改动策略 |

**买入点、卖出点和止损点首先是可计算的触发条件，不是保证成交的价格。** 收盘触发止损后，下一交易日仍可能因跳空、停牌或交易限制而以不同价格成交或暂时无法卖出；结果必须展示实际模拟成交及原因。

止损、止盈可以不启用，但必须在规则卡上明示；缺失字段不能悄悄等同于用户选择了不启用。没有普通卖出信号的策略，须明确仅按哪项风险或持有期限规则退出，或明确持有至区间结束；不能把遗漏卖出规则当作完整策略。

### 2.2 回测必需配置

| 参数 | 用户需要知道什么 | 填写规范与默认值 |
|---|---|---|
| 资金规模 | 开始时有多少钱 | 初始现金必须大于 0，默认 100,000；币种与股票柜台一致，默认初始空仓。资金规模与仓位分开设置 |
| 回测区间 | 用哪段历史验证 | 指定开始、结束日期，包含边界；默认最近 3 年，截至最新完整交易日。数据不足须显示缺口，不静默缩短区间 |
| 交易费用 | 每次交易扣哪些成本 | 显示佣金、最低佣金及适用税费，匹配市场与历史生效日期；未知费用不能按 0 处理 |
| 滑点 | 成交价比参考价差多少 | 默认每边 0.1%（10 bps），买入上调、卖出下调；作为可见模拟假设保存，不宣称是真实成交偏差 |
| 成交约束 | 有信号时是否真的能买卖 | 应用交易单位、可卖数量、停牌、价格限制及成交量约束；默认数量上限为前一有效交易日成交量的 1%，并校验当日成交量上限。约束与未成交原因可查看 |
| 比较基准 | 用什么判断策略表现 | 默认同股票、同区间买入持有，使用同资金、公司行动、费用及成交约束；基准无法计算时明确原因，不伪造对比结果 |
| 期末持仓处理 | 回测结束还有股票怎么办 | 默认不强制卖出，按末日收盘估值，未实现盈亏单列；不把期末持仓当成已完成交易 |
| 数据与版本 | 这次结果依据什么产生 | 系统保存策略版本、数据快照、指标／交易规则／费用／计算版本及假设，用户可在运行说明中查看 |

这些默认值是可见的产品设计选择，不是投资建议或已验证的最优参数。运行前必须展示用户输入、系统默认值和仍待补充项；点击「运行回测」即确认本次规则和配置，无需额外逐项弹窗。

## 3. 策略制作流程

1. **描述想法**：主入口为「说说你的交易思路」，提供可点击的口语示例；用户可只描述部分思路，不必先选择指标。保留直接填写规则和从模板创建的入口。
2. **AI 生成策略卡**：识别标的、资金、买卖意图和风险约束，自动填入对应字段；从已支持指标中提出可计算的规则与参数，配一句白话解释。已有信息不要求重复填写。
3. **补充关键缺项**：先展示已生成内容，只追问影响策略含义或执行的缺项，每轮优先解决 1～2 个问题；提供简短选项，也可自由回复。日期、滑点等可用已有默认值预填，来源明确标注。
4. **检查可运行性**：检查规则、参数和数据能力；「风险小一点」等描述先提供具体修改选项，再由用户选择。用户可直接改卡片，也可继续对话；两种方式更新同一份草稿。
5. **保存并运行**：未补全策略可保存草稿；只有规则完整、参数合法且通过数据检查后才能进入回测计算。每次运行绑定固定的策略版本和配置。
6. **修改并重跑**：用户从结果返回策略编辑，修改后产生新版本；旧版本、旧结果保留，可查看两次运行改了哪些条件。

首版沿用行情主区、右侧 AI 策略助手与规则卡、下方回测结果的工作台结构。入口突出「AI 帮我创建策略」和「我的策略／回测记录」，模板作为辅助；窄屏以「行情／策略／结果」切换，核心操作不依赖桌面侧栏。规则卡先展示「何时买、何时卖、投入多少、如何控制亏损」等白话摘要，指标公式与详细参数可展开查看。

### 3.1 AI 自动填充什么

| 用户表达或已有上下文 | AI 辅助动作 | 用户看到的内容 |
|---|---|---|
| 「用 10 万港币做腾讯，每次一半仓位」 | 解析并填入标的、币种、初始资金、50% 目标仓位；证券重名或柜台不明确时给候选 | 已填策略卡，标注「来自你的描述」；若沿用当前图表标的，注明来源 |
| 「上涨趋势形成后买，趋势转弱就卖」 | 提出受支持的趋势判断方案，例如短均线上穿／下穿长均线；填入对应指标与参数建议 | 白话含义、指标名称、参数、买卖条件和建议理由；注明这是可修改的量化方案，不是原话唯一含义 |
| 「收盘时这笔持仓净亏损到 5% 就退出」 | 填入收盘检查、固定止损 5%、下一交易日开盘执行，并展示本轮持仓净收益口径 | 止损规则及执行说明；若只说「亏 5%」，需澄清是股价跌幅还是持仓净亏损 |
| 未说明常用指标参数、回测日期或滑点 | 从已验证的指标目录／产品默认配置预填；买卖条件、仓位和风险阈值可提出建议，但不能当作用户已指定 | 每项标注「系统默认」或「AI 建议」，可直接修改；缺少关键决策的字段标「待补充」 |
| 「把半仓改成三成，其他不变」 | 将目标仓位从 50% 改为 30%，保留其他条件与用户手动编辑；重新检查完整性 | 修改前后差异；确认后保存新版本，可再次回测 |

自动填充覆盖策略指标的**名称、周期参数、阈值、条件关系**，以及资金、仓位、执行周期等配置；具体日期的指标数值由行情计算服务提供，收益、胜率等属于回测输出，不能由 AI 预填。

### 3.2 如何减少操作而保留可控性

- **先给草稿，再补缺项**：即使只输入一句不完整想法，也展示已理解的内容和待补充项，不直接退回一张空表单。
- **建议可解释、可替换**：先给一套简单方案，并说明指标在规则中起什么作用；用户可说「换一种判断方法」。不把建议描述为最优参数或收益保证。
- **确认集中在策略卡**：可见、无歧义的 AI 建议和系统默认值随「运行回测」一并确认；存在标的歧义、条件冲突或尚未选择的关键含义时，只追问对应项，不增加逐字段确认弹窗。
- **编辑与对话保持一致**：任何修改都以最新草稿为准，展示本轮变化；AI 不覆盖用户已明确的数值。生成失败时保留已填内容，可重试或手动完成。
- **真实配置有来源**：费用、交易单位、历史覆盖由系统读取已配置资料并校验；未知内容标待补充，AI 不能为了填满表单而编造。
- **能力不足给出下一步**：对盘中触价、多股组合等当前不支持的想法说明限制，可提供受支持的替代方案；用户选择后再转换，不静默改写原意。

模型负责理解、建议、填充和解释；信号、成交、资金、费用与绩效由确定性计算产生。缺数据时不得由模型补写收益或交易记录。

### 3.3 不懂指标也能开始的示例

用户输入：「我想拿 10 万港币做腾讯，上涨趋势形成后买一半，趋势转弱就卖，每天收盘看一次。」

AI 先填入腾讯港币柜台、100,000 港币、50% 仓位和日线检查；将「趋势形成／转弱」建议量化为「5 日均线上穿 20 日均线买入，下穿时卖出」，同时填写 MA(5)、MA(20) 及交叉条件。卡片解释：「短期平均价格向上穿过长期平均价格，作为本方案判断趋势转强的条件」，并标注「AI 建议，可修改」。这组参数仅用于演示如何构建规则。

随后只追问尚未明确的止损安排，例如「是否设置单笔持仓的收盘止损？」可选择「设置止损，填写比例」或「不启用止损」。回测区间等按 §2.2 预填。用户补齐关键项、核对费用与数据后，即可点击「运行回测」；之后说「把短均线改成 10 天」，AI 更新对应指标与规则引用，并展示本轮修改。

### 3.4 买卖规则配置窗口

**提供可视化交互窗口，让用户直接查看、添加和修改买卖条件。** 策略卡上的「配置买卖规则」打开窗口；AI 生成后，同一窗口自动展示已填条件。桌面采用宽抽屉，手机采用全屏编辑页，不在狭窄聊天栏中堆叠复杂条件。

窗口分为「买入规则」「卖出规则」两个页签；止损／止盈另设清晰的查看与配置入口，沿用 §2.1 的退出优先规则。买入和卖出分别维护条件组合，切换页签保留未应用内容。

| 控件 | 用户可配置的内容 | 交互要求 |
|---|---|---|
| 指标与数值来源 | KDJ 的 K／D／J、MACD 的 DIF／DEA、均线、成交量等 | 按中文名称选择，指标参数就地展开编辑；只提供已支持的指标和输出字段 |
| 比较条件 | 低于、高于、不高于、不低于、等于、上穿、下穿 | 按字段类型提供可用选项；上穿／下穿有白话解释，不与普通大小比较混用 |
| 比较对象 | 自定义数值或另一指标／数据字段 | 数值显示单位；例如 J 值阈值为数值，不是百分比，不能将 J 或其阈值强制限制在 0～100 |
| 持续条件 | 当日满足，或最近连续 N 个交易日满足 | 显示作用于哪一条条件；首版 N 为 1～20 的整数，使用已完成日线。KDJ 当日达标与连续放量可分别设置 |
| 条件组合 | 「同时满足以下条件」或「满足任一条件」 | 支持新增条件、删除条件、新增条件组；用缩进与括号显示组的范围，可表达「A 且（B 或 C）」；高级项可对条件取反 |
| 成交量快捷条件 | 连续放量：最近 N 个交易日，每日成交量都大于前一个交易日 | 直接填写 N，并展示比较基准；不能只显示没有定义的「连续放量」开关 |
| 规则预览与操作 | 白话摘要、字段错误、应用修改、取消 | 编辑时实时更新摘要；错误定位到具体字段。应用后更新策略卡与 AI 上下文，不自动启动回测；取消丢弃本次窗口修改 |

买入规则示意（20 与 3 为可修改的示例值）：

```text
配置买卖规则                         [关闭]
[买入规则]  [卖出规则]              [止损／止盈]

组合关系：[同时满足以下条件 ▾]
  条件 1：[KDJ ▾] [J 值 ▾] [低于 ▾] [20]
          参数：[9, 3, 3]   持续：[当日满足 ▾]
  条件 2：[连续放量 ▾]  [3] 个交易日
          每日成交量 > 前一个交易日成交量
  [+ 添加条件]  [+ 添加条件组]

规则预览：当日 J 值 < 20，且最近连续 3 个交易日
          成交量逐日增加时，产生买入信号。
执行说明：收盘后判断，下一交易日开盘模拟执行。
                                   [取消] [应用修改]
```

卖出页签使用相同编辑方式，例如「J 值高于 80，或 MACD 死叉」；与止损同时触发时仍只形成一次退出。示例阈值不作为默认交易建议。

AI 与窗口编辑必须双向同步：用户说「J 小于 20，同时连续放量 3 天」，AI 填入两条条件、参数和「同时满足」关系，并显示放量的具体解释；用户改成 J＜15 后，下一轮 AI 必须读取最新值。窗口打开期间若 AI 更新了草稿，应用时提示版本冲突并展示差异，不覆盖任一方修改。

### 3.5 连续放量与组合条件的判定口径

- 本版将「连续放量 N 天」定义为：截至信号日，最近 N 个交易日的成交量分别大于各自前一交易日，需要 N＋1 根完整日线作为比较依据。例如连续 3 天需要比较 4 天成交量；不是累计成交量变大，也不是仅高于均量。
- 最近 4 个交易日成交量依次为 100、120、150、180 万股时，连续放量 3 天成立；100、120、110、180 万股时不成立。相等不算放量，已知停牌或零成交日中断连续性；周末与交易所休市日不计入天数，未知数据缺口标为数据不足。
- 示例中的两条条件在同一个信号日合并判断：J＜20 只检查当日，连续放量检查截至当日的连续窗口；不自动要求 J 也连续 3 天达标。若用户需要两者都持续，分别设置持续条件。
- 「放量」若指高于过去均量或增加指定比例，须先明确口径；窗口和引擎未支持的口径说明能力不足，不擅自替换为逐日递增。
- 空条件组、缺阈值、非法天数、类型不匹配阻止应用；指标未预热或历史不足可以保存规则，但不能显示为条件未满足或回测成功。条件组超出系统可支持规模时提示精简，不静默删除条件。

### 3.6 策略市场的内容要求

**规则有明确数值，只能说明可以计算，不代表具备交易可行性。** 原 P-1.3 指定的 MA(5,20)、MACD(12,26,9) 与「J＜20＋连续放量 3 天」三套默认模板，撤销为首批必上架策略的要求；相关数字仅保留为规则编辑／计算示例，不进入正式市场的默认推荐。本次不预先认定具体策略有效。

正式市场条目须具备以下内容，不能靠临时拼接指标凑出目录：

| 内容 | 要求 |
|---|---|
| 策略思路与来源 | 说明逻辑、来源名称、链接或内部研究记录、整理日期；区分原始规则和平台改编，确认展示与使用权限 |
| 假设与失效情形 | 说明试图捕捉什么现象、假定的市场环境，以及可能失效的情况；未经验证的适用范围标为假设 |
| 完整规则与参数 | 买入、卖出、仓位、止损状态、执行周期均明确；具体阈值须有出处或标明平台待验证配置，不能用「适当」「低位」代替 |
| 支持范围 | 单股票／日线等执行能力与市场范围；当前不支持的规则只作说明，不提供可用的复制回测入口 |
| 规则校验状态 | 未校验／校验通过，并关联版本及记录；只表示规则可表达、可计算 |
| 历史回测证据 | 未回测／有历史模拟记录；有记录时展示标的、区间、资金、费用、滑点、基准、数据与引擎版本、净值和交易明细；标明样本内／样本外 |
| 版本信息 | 策略 ID、版本、更新日期、变更说明；源版本更新不修改用户已复制的策略 |

规则校验与回测证据分开展示。未回测时不填收益数字；某只股票、某个区间的结果不能扩展成全市场有效。没有达到上架要求的内容时，市场显示真实空态和「使用 AI 创建策略」入口，不自动用演示样例填充。

### 3.7 策略市场页面与交互

| 页面区域 | 首版功能 |
|---|---|
| 市场顶部 | 「策略市场／策略工作台」二级切换；搜索策略名称、标签；提供「AI 创建策略」入口 |
| 分类与筛选 | 按策略思路（趋势、均值回归、量价等）、执行周期、支持市场、规则校验状态、回测证据筛选；类别仅有实际内容时展示 |
| 策略卡片 | 名称、一句话逻辑、来源、类别、支持范围、版本与两类验证状态；点击查看详情。默认按更新时间排序，不预设收益排行榜 |
| 策略详情 | 按「思路与假设 → 买卖规则与具体参数 → 仓位与风险控制 → 历史回测证据 → 来源与版本」展示；完整规则无需复制后才能查看 |
| 详情操作 | 主操作「复制到我的策略」，次操作「让 AI 解释策略」；未通过规则校验或引擎不支持时禁用复制并说明原因 |
| 页面状态 | 加载中、加载失败可重试、无策略、筛选无结果、条目已下架分别展示；不以空列表掩盖接口失败 |

详情中的规则采用 §3.4 同一套可视化组件，以只读方式展示。点击「复制到我的策略」后，创建当前用户的独立草稿，进入工作台编辑，不修改市场原版；只有用户主动运行时才开始回测。

复制保留规则、参数、来源与市场版本，将数值标为「策略原版参数」。用户选择自己的标的、资金、回测区间并核对费用；详情中的历史业绩只属于原证据记录，不随复制显示成用户的新回测结果。切换标的或参数后显示「当前配置待回测」。若用户描述已明确部分参数，以其要求覆盖对应项并展示差异。

AI 可以解释原策略、提示假设与缺项、根据用户要求修改规则；解释时保留原参数，不擅自优化。已下架版本停止新复制，用户已有副本保留来源及下架提示，仍由独立的数据与执行校验决定是否可运行。

市场分两步交付：先完成页面、详情结构、来源与状态展示；再接通复制到工作台、AI 修改和回测。只有第一步完成时，仅能称为市场浏览能力，不能宣称完整策略使用闭环已完成。

## 4. 回测查看需要回答什么

**输入参数说明如何测试；结果指标说明这次历史模拟表现如何。** 用户应能同时看懂赚了多少、承担多大回撤、为何发生每笔交易，以及结果用了哪些假设。

| 结果区域 | 必须展示 | 口径与交互要求 |
|---|---|---|
| 收益概览 | 初始资金、期末权益、净利润、总收益率、年化收益率 | 权益包含现金、持仓市值及应收股息等权益；总收益率＝期末权益÷初始资金−1，已扣模拟费用。年化按实际日历天数折算，不足一年标注短样本 |
| 风险表现 | 最大回撤、收益波动率、夏普比率 | 最大回撤表示权益从历史高点跌到后续低点的最大幅度；展示波动率／夏普计算口径，无风险利率默认 0。样本不足或收益标准差为 0 时不硬算夏普 |
| 图表对比 | 策略与基准净值、回撤曲线、K 线买卖标记 | 信号点和成交点使用不同标记；点击可查看条件、成交价、数量与费用 |
| 交易统计 | 完成交易数、胜率、盈亏比、平均持有交易日数、换手与总费用 | 一次建仓至清仓计一笔完成交易。胜率按含费用与分红后的盈利交易数÷完成交易数；盈亏比按平均盈利额÷平均亏损额绝对值；持有天数按完成交易平均，换手展示分母 |
| 交易明细 | 买卖时间、触发原因、委托／成交数量、成交价、费用、已实现盈亏 | 包含拒绝、部分成交及未成交原因；未平仓交易单列未实现盈亏，不加入胜率与已完成交易统计 |
| 运行说明与历史 | 策略版本、全部配置、数据覆盖、数据质量、假设、历次结果 | 可返回对应版本继续修改；对比前列出区间、币种、数据与费用差异，同口径才直接排名；保留失败和较差运行 |

零交易时展示「本区间无成交」，胜率和盈亏比为「不适用」，不能写成 100% 胜率；没有亏损样本时盈亏比同样为「不适用」。用户可在改参区间以外另选历史区间，固定规则再验证，并保留两次记录。

运行状态包括排队、准备数据、计算中、成功、数据不足、失败、已取消。失败或数据不足时保留输入、说明具体原因与可修正项，不发布完整绩效；成功报告明确标注「历史模拟」。

## 5. 完整策略示例

以下为规则填写示例，不预设或编造回测收益：

| 项目 | 示例内容 |
|---|---|
| 名称与标的 | 腾讯 MACD + KDJ 日线策略；腾讯控股 00700.HK，HKD 柜台 |
| 资金与仓位 | 初始空仓，100,000 港币；空仓时按信号日收盘账户权益的 50% 生成买入目标，现金不足时向下缩量，持仓中不加仓 |
| 买入点 | MACD 的 DIF 从下向上穿过 DEA，且 KDJ 的 K＜30，两者同时满足 |
| 卖出点 | DIF 从上向下穿过 DEA，退出全部可卖持仓 |
| 止损点 | 每日收盘检查，本轮持仓净收益率 ≤−5% 时退出；止盈和最大持有期限均不启用 |
| 指标参数 | MACD：12、26、9；KDJ：9、3、3。交叉需比较前一根与当前已完成日 K，预热不足不发信号 |
| 执行周期与优先级 | 每个交易日收盘判断，下一交易日开盘模拟执行；退出优先、退出当日不重新入场 |
| 回测配置 | 2022-01-01 至 2025-12-31；每边滑点 0.1%；成交量约束沿用 §2.2；基准为同股票买入持有；期末不强平 |
| 费用与数据检查 | 选择覆盖该区间的港股税费表、明确券商佣金及最低佣金，核对行情、预热和公司行动覆盖；记录费用配置与数据快照后才可运行 |

这份示例已说明规则结构；费用或数据未配置齐全时仍是待补全草稿，不能直接产出回测结果。用户把 K＜30 改为 K＜20 后保存新版本，保持其他配置一致再回测，查看交易次数、收益和回撤的变化。

## 6. 产品验收标准

| 验收项 | 通过条件 |
|---|---|
| 能制作 | 用户能从空白开始，用自然语言或规则表单完成策略，并编辑、保存、重新打开；仅查看模板不算通过 |
| AI 降低门槛 | 用户不输入指标名称或代码，仅以 §3.3 的口语描述即可得到已填策略卡，包含建议指标、参数、买卖条件与白话解释；不能仅返回一篇策略说明 |
| 填充可控 | 用户明确的信息准确映射；用户输入、当前上下文、系统默认、AI 建议和待补充项可区分；未知费用和历史指标数值不得编造 |
| 对话可迭代 | 支持补充缺项、解释规则和指定字段修改；「其他不变」不改动无关配置，不覆盖手动编辑；生成失败后保留草稿 |
| 规则可视化配置 | 买入／卖出窗口支持指标字段、阈值、持续天数及条件组编辑；「J＜20 且连续放量 3 天」能从 AI 生成、手工修改到保存重开保持一致 |
| 组合含义正确 | AND／OR 及分组不混淆；连续 3 天比较 4 根日线，相等、中途缩量、停牌与缺失数据按 §3.5 处理；J 当日阈值不被误扩展为连续阈值 |
| 编辑状态可靠 | 应用与取消有效、买卖页签互不串改、关闭未应用窗口提示保留或放弃；AI 并发修改触发版本冲突提示；手机可完整编辑 |
| 市场独立页面 | 交易策略下可进入市场列表及详情；筛选、返回原列表状态、手机二级导航、空态／错误／下架状态可用 |
| 市场内容可信 | 每条已上架策略有完整规则、来源和假设，规则校验与历史回测状态分开；无证据不展示收益，编辑器示例不自动上架 |
| 复制后可制作 | 通过校验且受支持的条目可复制成当前用户独立草稿，保留源版本；修改不影响原版，原回测结果不移植为用户结果，市场下架阻止新复制 |
| 定义完整 | 资金规模、仓位、买入点、卖出点、止损状态、执行周期和回测区间均可明确查看；费用与假设已展示，缺失项准确提示 |
| 规则可执行 | 模糊条件、非法比例、未来数据条件及不支持的能力被拦截；日线止损不会被描述为盘中触价成交 |
| 结果可核对 | 收益可追溯至资金、持仓、交易与费用；有信号但未成交、零交易、期末持仓均有正确展示 |
| 可以迭代 | 修改生成新版本、重跑保留旧结果，同一组固定输入可复现；比较时展示配置差异 |
| 状态可信 | 数据不足、失败、取消与成功可区分；不能用模拟示例数据冒充真实历史回测完成 |
